# PROJECT: AI-Based Detection and Classification of Industrial Fires and Persistent Thermal Sources

You are the lead engineer responsible for building a **presentation-ready full-stack ML/DL prototype** for this project.

The repository is completely empty.

Build the project from scratch with three connected layers:

1. **ML/DL pipeline**
2. **Stable FastAPI backend**
3. **React frontend/dashboard**

The current objective is a functional prototype that can be demonstrated end-to-end.

## CORE PROJECT OBJECTIVE

The system should eventually identify and classify thermal anomalies using:

* NASA FIRMS thermal anomaly data
* OpenStreetMap/geospatial context
* satellite imagery/satellite-derived information

The long-term classification objective includes:

* Industrial fire
* Persistent industrial thermal source
* Wildfire
* Agricultural burning
* Other thermal anomaly

The system should eventually support:

* thermal anomaly detection
* classification
* persistence analysis
* anomaly detection
* confidence scoring
* geospatial visualization
* explainability

However, **do not attempt to implement everything simultaneously.**

The first priority is:

> Build a stable presentation-ready application around a scientifically defensible ML baseline, with architecture that can progressively evolve into the multimodal ML/DL system.
